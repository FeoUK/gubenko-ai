# Roadmap

## v0.1.0 — Professional Foundation

- Establish positioning and professional summary
- Create competency and technology inventories
- Register the initial project portfolio
- Define the case-study format
- Define privacy and publishing controls
- Prepare the repository architecture

## v0.2.0 — Evidence-Based Portfolio

- Complete the first five case studies
- Add sanitized diagrams and screenshots
- Record contribution, constraints, decisions and results
- Separate completed, operational, MVP and concept-stage work

## v0.3.0 — CV System

- Build the English master CV
- Produce Ukrainian and Russian versions
- Generate targeted variants for AI architecture, automation, consulting and infrastructure roles
- Add ATS-friendly export

## v0.4.0 — Publishing Pipeline

- Create LinkedIn and long-form publication templates
- Add editorial calendar and approval workflow
- Generate posts from approved case data
- Keep human approval before external publication

## v0.5.0 — Website

- Build the public Gubenko AI site from structured repository data
- Add portfolio pages, profile, CV and contact workflow
- Implement automated preview and deployment

## v0.6.0 — Opportunity Intelligence

- Define target markets and platform profiles
- Collect vacancies and contract opportunities through permitted interfaces
- Score opportunities against skills and cases
- Generate tailored CV and cover-letter drafts
- Track applications and outcomes

## v1.0.0 — Professional Career Platform

- One structured source of truth
- Public website and portfolio
- Multilingual CV generation
- Controlled publication pipeline
- Opportunity matching and application tracking
- Privacy, evidence and quality gates
