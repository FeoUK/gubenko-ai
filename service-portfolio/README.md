## Engineering approach

1. Clarify the operational problem and security boundaries.
2. Separate confirmed requirements from assumptions and future ideas.
3. Design the smallest architecture that can be validated in practice.
4. Build an MVP or pilot with observable behaviour and documented decisions.
5. Add monitoring, recovery and maintainability before calling the system production-ready.
6. Preserve evidence: architecture notes, screenshots, test results, logs and deployment documentation.
